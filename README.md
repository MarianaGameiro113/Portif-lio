# 💼 Portfólio Web - Mariana Gameiro

## 📋 Descrição

Este projeto é uma página de **Portfólio / Currículo Web** desenvolvida em HTML5. A página apresenta informações pessoais, habilidades, projetos desenvolvidos e um formulário para contato.

O projeto foi criado como atividade do curso de **Desenvolvimento de Sistemas do SENAI**, com o objetivo de praticar a estrutura semântica do HTML e a organização de uma página web.

## 🎯 Objetivo

Criar um portfólio simples, organizado e funcional utilizando **HTML5**, aplicando elementos semânticos, tabelas, links, imagens e formulários.

## 🛠️ Tecnologias Utilizadas

- HTML5
- Links internos e externos
- Formulários HTML
- Tabelas HTML
- Fieldset e Legend
- Elementos semânticos

## 📌 Estrutura do Projeto

A página possui as seguintes seções:

### 👩 Sobre Mim
Apresentação pessoal, foto de perfil e informações sobre conhecimentos em desenvolvimento web.

### 💻 Minhas Habilidades
- HTML
- CSS
- JavaScript

### 📁 Projetos
A página apresenta uma tabela com projetos desenvolvidos, suas tecnologias, status e links para os respectivos repositórios no GitHub.

Projetos apresentados:

- Loja de Games Retro
- Verificador de Maioridade
- Projeto Filme

### 📩 Entre em Contato
Formulário contendo:

- Nome completo
- E-mail
- Assunto
- Mensagem
- Botão de envio
- Botão para limpar os campos

### 📞 Rodapé
Contém informações de direitos autorais, e-mail e telefone para contato.
